Reusable enterprise patterns.

Initial catalog: Enterprise RAG, AI Gateway, Multi-Model Routing, Agentic AI, Multi-Agent, AI Factory, LLMOps, AgentOps, AI Observability, AI Security, AI Governance Control Plane, Human-in-the-loop, AI FinOps.

Each pattern should document: Problem, Context, Architecture, Components, Data Flow, Security, Governance, Operations, Cost, Risks, Trade-offs, and Implementation.
